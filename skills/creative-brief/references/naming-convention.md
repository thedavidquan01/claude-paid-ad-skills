# Naming convention

Name every ad so the Monday read can split it on underscores. The name carries the cell, the version, and the one thing that changed.

```text
DATE_BRIEF-VARIANT_TOPIC-ANGLE_PERSONA_STAGE_LEVER_FORMAT
```

Made-up example:

```text
261026_B01-V2_Rostering-SundayNights_SHIFTMGR_PROBLEM_HOOK_IMG
```

| Part | Example | Meaning |
|---|---|---|
| DATE | 261026 | Launch Monday as YYMMDD |
| BRIEF-VARIANT | B01-V2 | Brief number and version, V1 to V4 |
| TOPIC-ANGLE | Rostering-SundayNights | The grid topic, then the why in a few words |
| PERSONA | SHIFTMGR | The who from the grid |
| STAGE | PROBLEM | Awareness stage |
| LEVER | HOOK | The one thing this version changed |
| FORMAT | IMG | The format |

## Allowed values

| Part | Values |
|---|---|
| STAGE | UNAWARE, PROBLEM, SOLUTION, PRODUCT, MOST |
| LEVER | ORIG (V1), HOOK (V2), CREATOR (V3), SETTING (V4). Any other single change, in capitals, such as PAGE or OFFER |
| FORMAT | VID, IMG, CAR (carousel) |

## Rules

- Use underscores only between the seven parts. Use hyphens inside a part.
- No spaces. Use CamelCase inside TOPIC-ANGLE.
- Keep one name per ad. Never rename a live ad. Copy it instead.
- A scaling copy keeps the same name in a campaign whose name contains `SCALE`.
